# 🏥 Disease Prediction System

A Machine Learning web app that predicts diseases based on symptoms.

## Features
- Search and select symptoms
- Real-time disease prediction
- Top 3 possible diseases with confidence scores

## Tech Stack
- Python
- Scikit-learn (Random Forest)
- Gradio (UI)
- Joblib (Model serialization)

## How to Run
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open: `http://127.0.0.1:7860`

### Live Link(deployed at render)
https://disease-prediction-system-xxjs.onrender.com/
Just click on this link, type starting letter of symptoms, then click on show matches, then check the symptom from suggestions, and selcted symptoms will be visible to u, search more symptoms, mark them checked and finally  click on predict disease and see the result
